# 📰 데일리 뉴스 브리핑 & Gemini AI 자동 요약기

> 별도의 외부 패키지 설치(`pip`) 없이, Python 기본 내장 라이브러리만으로 동작하는 경량 뉴스 브리핑 자동화 프로그램입니다.

---

## 📌 주요 기능
1. **RSS 피드 자동 수집**: `settings.json`에 정의된 언론사 RSS 주소에서 최신 뉴스를 수집합니다.
2. **키워드 우선순위 필터링**: `은행`, `ai`, `금융` 등 설정된 키워드가 포함된 기사를 최신순으로 우선 배치하고, 모자라면 일반 최신 기사로 채워 **최대 5개**를 선별합니다.
3. **Gemini AI 1~2줄 핵심 요약**: 바쁜 직장인을 위해 선별된 기사의 핵심 내용을 1회의 초고속 일괄 요청으로 요약합니다.
4. **3가지 포맷 동시 생성**:
   - `news.json`: 다른 프로그램과 연계하기 쉬운 데이터 파일
   - `briefing.md`: 노션, 옵시디언, 깃허브 등에 바로 쓰는 마크다운 문서
   - `index.html`: 브라우저에서 바로 열리는 반응형 카드 대시보드

---

## 🚀 실행 방법

### 방법 1. 간편 실행 (윈도우)
폴더 안의 **`run.bat`** 파일을 더블 클릭하면 자동으로 뉴스를 수집/요약하고 브라우저에 결과를 띄워줍니다.

### 방법 2. 터미널 실행
```bash
python briefing.py
```

---

## 📂 파일 구조
- `settings.json` : 수집할 RSS 주소 및 감지 키워드 설정
- `.env` : Gemini API 키 보관 파일 (Git 업로드 제외)
- `briefing.py` : 전체 파이프라인 자동화 파이썬 스크립트
- `news.json` : 수집 및 선별된 최종 5개 기사 JSON 결과
- `briefing.md` : 마크다운 브리핑 리포트
- `index.html` : 반응형 웹 대시보드
- `run.bat` : 더블 클릭 원클릭 실행 배치 파일
